# Doctor Web Page - Telemedicine System

A pure front-end static web page for doctors to receive patient calls and conduct video consultations.

## 📁 File Structure

```
doctor-app/
├── index.html      # Main HTML structure
├── style.css       # All styling and animations
├── script.js       # Application logic and call simulation
└── README.md       # This file
```

## 🚀 Quick Start

1. **Open the page:**
   - Simply open `index.html` in any modern web browser
   - Or deploy to GitHub Pages (see below)

2. **Test the application:**
   - The page will automatically simulate incoming calls after 5 seconds
   - Click "Accept Call" to start video consultation
   - Click "Reject Call" to dismiss the call

## ✨ Features

- ✅ **Pure Front-End** - No backend, no server required
- ✅ **Responsive Design** - Works on desktop and mobile
- ✅ **Ringing Animation** - Visual alert when call arrives
- ✅ **Jitsi Integration** - Embedded video call when accepted
- ✅ **Status Management** - Available/Busy status indicators
- ✅ **Call Simulation** - Automatic incoming call simulation

## 📋 How It Works

1. **Idle State:**
   - Doctor status shows "Available"
   - Page displays "Waiting for incoming calls..."

2. **Incoming Call:**
   - After 5 seconds (or every 30-60 seconds), a call is simulated
   - Ringing animation appears
   - Patient information is displayed (Name, ID, Symptoms)

3. **Accept Call:**
   - Click "✅ Accept Call" button
   - Jitsi video call iframe loads
   - Status changes to "Busy"
   - "End Call" button appears

4. **Reject Call:**
   - Click "❌ Reject Call" button
   - Call is dismissed
   - Returns to idle state
   - Next call will be simulated automatically

5. **End Call:**
   - Click "End Call" button
   - Video call closes
   - Status returns to "Available"
   - Next call simulation starts after 5 seconds

## 🎨 Customization

### Change Call Simulation Interval

Edit `script.js`:
```javascript
// In startCallSimulation() function
appState.callInterval = setInterval(() => {
    // ...
}, 30000 + Math.random() * 30000); // Change these numbers (in milliseconds)
```

### Change Jitsi Room URL

Edit `script.js`:
```javascript
// In acceptCall() function
const jitsiUrl = 'https://meet.jit.si/AmazedResortsStoreAnnually'; // Change this URL
```

### Modify Patient Data

Edit `script.js`:
```javascript
const samplePatients = [
    {
        patient_name: 'Your Patient Name',
        patient_id: 'PAT-XXX',
        symptom: 'Patient symptoms'
    },
    // Add more patients...
];
```

## 🌐 GitHub Pages Deployment

1. **Create a GitHub repository**

2. **Upload files:**
   - Upload `index.html`, `style.css`, and `script.js` to the repository

3. **Enable GitHub Pages:**
   - Go to repository Settings → Pages
   - Select source branch (usually `main`)
   - Click Save

4. **Access your page:**
   - Your page will be available at: `https://yourusername.github.io/repository-name/doctor-app/`

## 🔒 Security Notes

- This is a **static front-end only** application
- No data is stored or transmitted
- Jitsi video calls require HTTPS in production (GitHub Pages provides this)
- Camera/microphone permissions will be requested by the browser

## 🐛 Troubleshooting

**Q: Video call not loading?**
- Ensure you're using HTTPS (GitHub Pages provides this)
- Grant camera/microphone permissions when prompted
- Check browser console for errors

**Q: Calls not appearing?**
- Check browser console for JavaScript errors
- Ensure `script.js` is loaded correctly
- Wait 5 seconds for the first simulated call

**Q: Ringing animation not working?**
- Check that `style.css` is linked correctly
- Ensure browser supports CSS animations

## 📝 Notes

- This is a **simulation** - calls are generated by JavaScript
- In production, you would connect this to a real backend API
- Patient data is hardcoded for demonstration purposes
- All functionality works offline (except Jitsi video call which requires internet)
